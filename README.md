# 西语词汇（esp_vocab）

西班牙语词汇四选一练习，支持安卓手机，也可以直接在浏览器里用。

- 看西语选中文 / 看中文选西语，按笔记页码出题
- 答错的词几题后复现，错题本里连续答对两次自动移出
- 西语朗读（安卓用系统文字转语音，浏览器用 Web Speech）
- 应用内导入新词表、备份和恢复学习进度
- 支持深色模式，离线可用

## 下载安装

到 [Releases](../../releases/latest) 页面下载最新的 `.apk`，传到手机上安装。手机可能会提示"允许安装未知来源应用"，按提示允许即可。

新版本直接覆盖安装，学习进度会保留。

**朗读没有声音？** 打开 系统设置 → 文字转语音（TTS），确认装了支持西班牙语的引擎和语音包。部分国产手机默认没有，需要另外安装。

## 目录结构

```
web/                 ← 网页本体：既能在浏览器里打开，也会原样打包进 APK
  index.html         界面和全部练习逻辑
  words.json         内置词库
  fonts/             Newsreader、JetBrains Mono 字体（中文用系统字体）
app/                 ← 安卓外壳（一个 WebView + 朗读 / 文件 / 返回键的桥接）
.github/workflows/   ← 推送到 main 后自动编译 APK 并发布
```

## 添加新单词

有两种方式，按需选择。

### 方式一：在应用里导入（不需要重新安装）

在应用首页的"词库与进度"里点 **导入词表**，选择手机里的文件。格式见应用里的"词表格式说明"，最简单的是每行一个词：

```
hola	你好	19
adiós	再见	19
```

西语、中文、页码之间用 Tab 或英文逗号分隔，页码可省略。同一个词再次导入会更新释义，学习记录不受影响。

### 方式二：改内置词库（所有新安装都会带上）

编辑 `web/words.json`，在 `words` 里追加词条，然后把文件里的 `version` 加 1：

```json
{"id":"n0418-p19-001","es":"hola","zh":"你好","p":19,
 "d":[["ola","波浪"],["hora","小时"],["bola","球"]]}
```

- `id`：唯一且不要改动，学习记录靠它关联。建议格式 `笔记名-p页码-序号`
- `p`：笔记页码
- `d`：干扰项，`[西语, 中文]` 的列表，建议 3–6 个形近词或同类词。可以省略，省略时会自动从同页的词里挑

推送到 main 分支后，GitHub 会自动编译出新版 APK，几分钟后出现在 Releases 页面。

## 自己编译

- 用 Android Studio 打开本目录，点 Build → Build App Bundle(s) / APK(s) → Build APK(s)
- 或在命令行运行 `./gradlew assembleRelease`（需要 JDK 17 和 Android SDK）

没有配置签名时，release 包会用调试签名，可以安装，但不能覆盖安装 GitHub 上下载的版本。

## 签名

GitHub 上的正式签名来自仓库 Secrets：`KEYSTORE_B64`（keystore 文件的 base64）、`KEYSTORE_PASSWORD`、`KEY_ALIAS`、`KEY_PASSWORD`。

**keystore 文件请妥善备份。** 丢失后，新版本将无法覆盖安装旧版本，只能卸载重装（卸载前先在应用里"备份进度"）。

## 在浏览器里使用

`web/` 需要通过本地服务器打开（直接双击打开时浏览器会拦截读取 `words.json`）：

```
cd web && python -m http.server 8000
```

然后访问 http://localhost:8000 。
